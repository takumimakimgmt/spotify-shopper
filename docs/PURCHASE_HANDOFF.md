# Recording comparison and purchase handoff

Results show Spotify and XML candidate titles and artist credits side by side. Differing words are highlighted for inspection only; matching rules and remembered confirmations are unchanged. Candidate album / ISRC are not available from current matching evidence and are explicitly identified as unavailable.

Beatport is the primary action, with Bandcamp a secondary alternative. HTTPS store URLs are allowlisted. Search URLs are labelled as searches; track URLs are labelled as track pages, never verified recording matches. Availability and version remain unverified. Configured affiliate attribution is applied consistently, including saved and exported links.

The results download exports non-owned rows from the current filtered view, including unchecked rows with their explicit status. Buy Later has a separate export for all saved candidates. These are static, responsive HTML files with escaped metadata, a restrictive content policy and no scripts, external assets, XML or library candidate evidence. Song details in the exported list are readable by anyone receiving the file. No upload or public sharing endpoint is created.

Send the file to a phone using an existing file-transfer method, then open it in a browser. File previews in messaging or file apps may handle links differently; opening in a browser is recommended. Reading the list works offline; visiting stores requires connectivity. Labels are snapshots and are not revalidated on the phone. iOS Safari and Android physical devices have not been tested.
